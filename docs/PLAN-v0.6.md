# v0.6 规划：文件面板页签 / 群聊 @ 与群优先 / 自动记忆校验

> 状态：**已完成（v0.6.0）**。P1/P2/P3 + 自动记忆校验均落地并通过 210 Host 单测 / 290 Client smoke / 真机验证。

## P1. 文件面板拆成两个页签
- 面板宽度 420 → 520（窄屏不变），目录/预览不再上下分栏。
- 页签：「浏览」（根目录下拉 + breadcrumb + 列表）与「预览」（文件 header + 内容）。
- 点文件自动切到预览；预览页签带返回浏览；两页签各自记住路径/滚动位置（按 chatId）。
- 聊天点击路径 → 打开面板并落到预览；Esc 关闭；与设置抽屉互斥。
- 验收：切页签不丢状态；代码/长 Markdown 可读；403/415 错误态正常。

## P2. 群聊 @ 与发言路由（Host + Client）
Client：
- 输入框 `@` 触发群成员选择器（头像/名字/角色，键盘上下+回车），插入 mention；支持 `@all`。
- 发送前提示「本轮将发言：Chief / Alice, Bob / 全部成员（最多 3 人）」。
- 消息中的 mention 高亮；空群状态引导「@成员 分派或发项目目标」。
Host：
- 群消息含 mention → 只让被 @ 成员发言（顺序按 mention 顺序）；无 mention → `admin` 模式管理员发言、`all` 模式按成员顺序但**默认最多 3 人**（群设置 `maxSpeakers`，0=不限）。
- 发言人上限在提示词里说明「其余成员待命」，避免 7 Bot 齐答。

## P3. 群优先协作与结果回流
- 提示词/工具引导：有项目群时，进度/问题/决策/派活先发群并 @ 成员；私聊只做一对一与敏感信息。
- 任务派单与后台助手：在群上下文发起时，结果 relay 回群；群内可见谁接单/完成。
- 群决策日志：群回合出现「结论：/决定：/约定：」时自动追加 group note（受 useNote 开关约束），header 可查看。
- 群 kickoff 建议：建群提示词要求 Chief 发首条 kickoff（目标/分工/目录/验收），并把目录写入群项目目录。
- 验收：让 Chief「给团队派活」时，消息出现在群里并 @ 成员；任务结果回群；群不再空。

## 自动记忆校验（已实测）
- 团队强指令 → 自动写入（auto:true，source:auto）。
- 团队普通偏好 → 待确认候选。
- Bot 强指令（含 Bot 名 + 记住/以后都）→ 自动写入该 Bot 记忆（auto:true）。
- Bot 普通偏好 → 待确认候选。
- 结论：自动生成已实现；本轮仅补强「Bot 专属强指令」触发词与测试覆盖，不改语义。
